# 📝 Заметки и Регистрация на WinAPI

Учебный проект на чистом C++ и WinAPI. Десктопное приложение для ведения зашифрованных заметок с системой регистрации и авторизации.

## 🚀 Возможности
- Регистрация и авторизация пользователей
- Создание, редактирование и удаление заметок
- Шифрование данных при сохранении на диск
- Полностью на WinAPI без сторонних фреймворков

## 🛠️ Технологии
- C++
- WinAPI (Windows API)
- Встроенная криптография Windows

## 💻 Как запустить
1. Клонируйте репозиторий: `git clone https://github.com/komap2007/registration-app.git`
2. Откройте файл `.slnx` в Visual Studio.
3. Соберите проект (Build -> Build Solution).
4. Запустите `.exe` из папки Release.

## ⚠️ Примечание
Проект создан в учебных целях для изучения WinAPI и основ информационной безопасности.
